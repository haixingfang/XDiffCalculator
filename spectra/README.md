# Tube reference spectra

Generated with SpekPy 2.5.4 (physics `casim`, reflection targets), not measured.
W: 40, 80, 120 kV. Cr/Cu: 40, 50 kV (the chosen model supports these targets only up to 50 kV).
All use 12-degree anode angle, 1 mm Be plus 1 mm Al filtration, 100 cm on-axis distance and 1 mAs.
Values are photon spectral densities in photons/cm²/mAs/keV, on 0.05-keV bins.
Both continuum and characteristic radiation are included. Zero samples at the band edges avoid extrapolation beyond the tube endpoint. The application interpolates these binned values; intrinsic characteristic-line widths are not represented.

The GUI only plots relative spectral weights, not absolute diffracted counts. Changing detector distance does not change this source's reference distance; specimen fluence would require a separate absolute-intensity model.

Generated by [tools/generate_spectra.py](../tools/generate_spectra.py). To regenerate, use a separate environment containing `spekpy==2.5.4`, and run that script from Python. SpekPy and its numerical dependencies are not needed by the application and are not bundled in the executable.

Sources:

- [SpekPy 2.5.4 release](https://pypi.org/project/spekpy/2.5.4/)
- [SpekPy Web methods and spectrum parameters](https://pmc.ncbi.nlm.nih.gov/articles/PMC10929988/)
- [Extension to additional target materials](https://pubmed.ncbi.nlm.nih.gov/41401626/)

For another source, import a CSV with header `energy_keV,photon_density` and strictly increasing energies. Bin-integrated experimental data must first be divided by each bin's width in keV.
